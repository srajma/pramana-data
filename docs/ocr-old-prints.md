## Findings (2026-10-06)

- **Production recipe confirmed:** Gemini 3.8 Flash with the tagged prompt (`pramana/scanocr.py`) reads every
  page (~$4 / 1,000 pages); Gemini 3.1 Pro (~$12 / 1,000) re-reads the doubtful ones (`pramana scans reread`).
  On these older prints Flash is 1.5 points behind Pro on average (median 0.7), with no gross failures — the
  same gap as on the modern editions of `docs/ocr-bakeoff.md`.
- **Commentary needs the tagged prompt.** Engines that transcribe the whole page (Datalab, Flash with the plain
  prompt) read the main text about as well ("error ignoring extra text" 5–6 %) but interleave commentary,
  footnotes and running heads with it, so their main text is 2–3× too long on every page with commentary.
  Datalab is therefore not used for scans: the tags (`@M` main text, `@C` commentary, `@T` translation,
  `@F` notes, `@H` page furniture) are what lets a commentary be split from its text.
- **Raw error against the library's editions (5–16 % on most scans) is mostly edition difference**, not OCR:
  checked by hand on Kirātārjunīya p. 85 (3.6 %, nearly all ś/s slips in the *reference*) and Manu p. 467
  (4 %). The Manu (Mandlik's six-commentary edition) and Bhāgavata-lithograph rows are dominated by verse order
  and recension differences. Scans without a clean edition (Vāyu Purāṇa 1880) were compared engine against
  engine: Flash and Pro differ by 2.3 % of letters there.
- **Lithographs:** checked by eye (Bhāgavata 1864, p. 93). Pro keeps the scribe's spelling and the unspaced
  writing (*apitu anye pi*, *kīdṛśaiḥ*); Flash silently normalises a few forms (*apitvanye*) and inserts spaces.
  Because lithographs run words together, dictionary-validity is low for them by nature (Pro 1–2 %), so the
  doubt test compares a page only with the rest of its own book.
- Some Digital Library of India items are not served by archive.org's IIIF image server (HTTP 400); their pages
  come from the BookReader endpoint (`/download/<id>/page/n<i>_w2200.jpg`) instead.
- An earlier version of the scorer folded ś to s in IAST references (NFD + accent stripping); fixed in
  `scripts/ocr_bakeoff.py:norm`.
